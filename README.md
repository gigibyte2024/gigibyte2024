## 🚀 Featured projects

### [FDF – Blinkit First-Order Intent Matcher](https://github.com/gigibyte2024)
> Next.js · Express.js · Socket.IO · PostgreSQL · Drizzle ORM · Auth.js

Real-time group ordering platform that matches users with similar Blinkit carts to collectively meet the ₹200 minimum threshold. Built with SOLID principles — Repository, Strategy, State, Observer, Service Layer, and Middleware patterns. Google Auth, real-time notifications, and smart order matching based on delivery location and checkout window.

---

### [EngageIQ AI – Classroom Engagement Monitoring](https://github.com/gigibyte2024)
> FastAPI · LangGraph · OpenCV · MediaPipe · YOLOv8 · PostgreSQL · React

AI-powered system analyzing webcam feeds to detect attention, drowsiness, distraction, facial expressions, and phone usage in real time. Multi-agent LangGraph workflow scores engagement and generates personalized nudges via Groq/Gemini LLMs. Privacy-first: all vision processing runs on-device.

---

### [FinSight AI – Financial Analytics Platform](https://github.com/gigibyte2024)
> React · FastAPI · Scikit-learn · Pandas · Matplotlib · OpenAI API

AI-powered platform that auto-categorizes expenses (TF-IDF + Multinomial Naive Bayes), visualizes spending patterns, and lets you ask finance questions in plain English via an LLM chatbot. REST APIs for data upload, analysis, chart generation, and financial Q&A.

---

### [Blueprint AI – AI Product Manager](https://github.com/gigibyte2024)
> Next.js · FastAPI · LangGraph · Gemini/Groq · PostgreSQL · Tailwind CSS

Multi-agent AI app that converts startup ideas into PRDs, API specs, database schemas, roadmaps, and risk analyses. 11-agent LangGraph workflow where specialized AI agents collaboratively generate structured product documentation. Supports PDF/Markdown export and an interactive workspace.
